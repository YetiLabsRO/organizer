What to expect

  • Only tasks assigned to you personally come in — not tasks you only reported or watch, and not tasks assigned just to a team you are in.
  • Title, description, start date, deadline, estimate, priority and status sync both ways. If the same field changed on both sides between syncs, the value from Organizer wins.
  • Every change sent to VolunHub notifies that task's watchers there, as if you had made it in VolunHub.
  • Organizer never creates or deletes tasks in VolunHub. Deleting a VolunHub task here only stops syncing it. A task unassigned or deleted in VolunHub stays here, marked as removed.
  • Some things stay local: the “given up” status (VolunHub has no equivalent), tags, sub-tasks, “for today”, and moving a task to another project here.
  • Tasks from VolunHub are not mirrored to Notion, so each task has a single external home.
Disconnecting revokes Organizer's access in VolunHub and deletes the stored credentials. Your imported tasks stay here.
